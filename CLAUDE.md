# Wyspy Wiedzy — notatki dla Claude

Aplikacja do nauki dla dziecka (klasa 3+), UI po polsku. React 18 + TypeScript + Vite, PWA, Supabase (opcjonalnie).

## Mapa kodu

- `src/types.ts` — typy: ćwiczenia (choice/tap/sort/fill/match/dictation; `hint` — podpowiedź po `??`), tematy (z `guide` — ściąga, `lesson` — lekcja trybu nauki, `words` — słówka „english = polski”, `unit` — rozdział, np. „Unit 0”), `Subject.lang` (język treści: `ang` → `en`), zdarzenia (Attempt z `answer` przy błędach, Session z `mode`: topic/review/test/diagnostic/gen/fix/sprint/pairs/learn (`durationMs` dla Par na czas; `learn` = przeczytana lekcja, bez odpowiedzi), Redemption), ustawienia (`familyGoal`, `pinLength`), Profile (`plan`, `quizzes` — kartkówki od rodzica; wynik = ukończona sesja `test` z `quizId`).
- `src/dsl.ts` — format tekstowy zadań (parser, serializacja, sprawdzanie luk). Id zadania = hash treści linii (bez `!!` wyjaśnienia). Linia `tekst: Tytuł >> treść` dołącza `passage` do pytań pod nią (id pytania zawiera tytuł tekstu); `tekst: koniec` kończy tekst. `?? podpowiedź` (przed albo po `!!`) też nie wchodzi do id. `parseLesson` — lekcja trybu nauki (sekcje `# Najważniejsze`, `# Krok po kroku`, `# Tak / nie tak`, `# Zapamiętaj`, `# Sprawdź się`). `parseWords` / `wordHints` — słówka tematu i podpowiedzi do słów w zdaniu; `normalizeAnswer` zrównuje apostrofy (’ = ').
- `src/content/seed.ts` (+ `math.ts`, `polish5.ts`, `english5.ts` — angielski kl. 5 ze słówkami i podpowiedziami-tłumaczeniami, `dictation.ts`, `reading.ts`, `guides.ts`, `lessons.ts` — lekcje trybu nauki (zasady pisania w nagłówku pliku), `util.ts`) — tematy wbudowane (DSL) z polem `grades`; ściągi w `guides.ts` (test wymaga ściągi dla każdego tematu). Matematyka generowana kodem (wyniki liczone). Zmiana treści linii zmienia id zadania → reset postępu tego zadania; wyjaśnienie po `!!` można zmieniać bez resetu.
- `src/longdiv.ts` — dzielenie pisemne („słupek”): kroki, układ zapisu jak w polskiej szkole (wynik nad kreską, przy zerze w wyniku bez osobnego „−0”) i opisy kroków dla dziecka; wszystko liczone z dzielnej i dzielnika. `writtenDivisionOf(ex)` rozpoznaje zadania „Oblicz pisemnie…” / „Dzielimy pisemnie a : b…” — po odpowiedzi ekran ćwiczenia rysuje gotowy słupek (`ui/LongDivision.tsx`).
- `src/content/generators.ts` — trening bez końca i Błyskawica (zadania losowane, `topicId` = `gen:<id>`, bez pudełek Leitnera). Generator z `slow: true` (zadania na kartkę, np. dzielenie pisemne) ma tylko „Trening” — bez Błyskawicy i Par na czas. `mulLine(a, b)` daje stałe id działania — na tym opiera się mapa tabliczki (`multiplicationMap` w engine, `TimesTable.tsx`). `rewardIdeas.ts` — pomysły na nagrody.
- Profile mają `grade`; `store.topicsFor(profileId)` filtruje tematy po klasie. Start = wybór przedmiotu (`Home`), potem `SubjectScreen`.
- `src/engine.ts` — CAŁY postęp wyliczany z dziennika: XP, monety, poziomy, seria (z zamrożeniami = Redemption `freeze`), kamienie milowe, pudełka Leitnera, poziomy tematów 0–4 (z zaliczeniem testem: ≥3 odpowiedzi i 80% w sprawdzianie/teście na start → reszta zadań wirtualnie w pudełku 2), cel tygodnia, oceny 1–6, zasady Błyskawicy, cel rodziny, „Moje błędy” (`mistakesToFix`), stan planu (`planStatus`: opanowanie potwierdza sprawdzian próbny z całego planu na 5–6; `planExamCount`: 3 pytania na temat, 15–30), kartkówki (`quizStates` — liczy się pierwsze ukończone podejście), lekcje (`lessonsDone`; pierwsze przejście lekcji = monety i dzień nauki), rozdziały (`groupByUnit`), mapa tabliczki (`multiplicationMap`, `weakestFacts`), układanie sesji (temat, czytanie — całe teksty, powtórka, sprawdzian, test na start).
- `src/data/store.ts` — magazyn: pamięć + IndexedDB (`idb.ts`) + synchronizacja z Supabase (tabela `ww_docs`, kursor po `server_updated_at`, kolejka outbox). Kolejność w `sync()`: `reconcile` (scalanie osób/tematów/ustawień z wersją w chmurze — `merge.ts`, pole po polu względem `base` z outboxa) → `flush` → `pull`. Kanał „na żywo” (`startLive`, Supabase Realtime `postgres_changes`) tylko wyzwala `pull`; zostaje odpytywanie co minutę. Urządzenie przy pierwszym logowaniu („joining”) przyjmuje ustawienia rodziny z chmury. `putMany` — zapis hurtowy; `mergeProfiles` — łączenie dwóch profili; `verifyPassword` — reset zapomnianego PIN-u hasłem konta.
- `src/ai.ts` + `supabase/functions/ai/prompt.ts` (wspólny plik z poleceniem) + `supabase/functions/ai/index.ts` (Edge Function, Deno). Dwa tryby: temat (`zapisz_temat`) i plan ze zdjęcia zakresu sprawdzianu (`mode: 'plan'`, `zapisz_plan` — pasujące istniejące tematy + najwyżej jeden nowy); oba też przez „skopiuj do czatu” (`parsePastedAnswer`, `parsePastedPlan`).
- `src/avatars.ts` — bohaterowie (emoji + polska nazwa + cena + grupa: zwierzaki / postacie / pojazdy / skarby); jedna lista dla zakładania osoby, sklepu, okna „Wygląd i bohater” i panelu rodzica. `ownedAvatars` — darmowi + kupieni + aktualny.
- `src/speech.ts` — czytanie na głos; głos wybierany według języka (`speak(text, rate, lang)`, `speakParts` — polecenie po polsku, zdanie po angielsku).
- `src/themes.ts` + `src/styles.css` — 6 motywów (Wyspy, Piloci, Pixel, Zeszyt, Kosmos, Wyścigi) przez `data-theme` i zmienne CSS; każdy ma układ planszy (`layout`), ikonę (`icon`), tytuł przedmiotu (`subjectTitle`) i własne słowa. `themeOf(id)` — motyw osoby z bezpiecznym domyślnym. Motyw nie zmienia logiki.
- `src/ui/` — ekrany: Home (plan, cel tygodnia, cel rodziny, test na start; SubjectScreen z 4 układami planszy i „Wyzwaniami”), Practice (rodzaje: `Run` w `hooks.ts`), Sprint (Błyskawica), Pairs (Pary na czas), TimesTable (mapa tabliczki), Learn (tryb nauki: karty lekcji + `ReviewSheet` — powtórka rozdziału/planu na jednej stronie), LongDivision (słupek: siatka, kroki w lekcji, rozwiązanie po odpowiedzi), ThemePicker (okno „Wygląd i bohater”: dziecko samo zmienia bohatera i motyw), ThemePreview (miniatury motywów przez lokalne `data-theme`), exercises/, Summary (ocena, „Co się zmieniło”, błędy), Rewards (zamrożenie), bits.tsx (Modal, LevelChip, ściąga), parent/ (Postępy z raportem i tabliczką, Plan i sprawdziany + PlanFromPhoto, Tematy, Dodaj, Nagrody z celem rodziny, Ustawienia).

## Zasady

- Nie zapisuj stanu pochodnego (XP, monet, gwiazdek) — dopisuj zdarzenia i licz w `engine.ts`. To gwarantuje synchronizację bez konfliktów.
- Nowy typ zadania: `types.ts` → `dsl.ts` (parse + `exerciseToDsl`) → `ui/exercises/logic.ts` (initial/ready/correct/correctText/summary) → komponent w `Exercises.tsx` → `supabase/functions/ai/prompt.ts` (opis formatu) → testy.
- Treści dla dziecka: bezbłędna polszczyzna, jednoznaczne odpowiedzi. Każdy temat wbudowany musi przejść `npm test` (test parsuje wszystkie).
- Polskie formy liczebników: `plural()` z `themes.ts`.
- Dzielenie pisemne: zadania twórz przez `writtenLine` / `guidedLine` z `math.ts` (wynik, reszta, podpowiedź i wyjaśnienie liczone w kodzie). W lekcji i ściądze linia „słupek: 936 : 4” rysuje zapis (w lekcji odsłaniany krok po kroku dużym przyciskiem). W tekście zadania z lukami „ // ” to nowa linia.
- Lekcje (`lessons.ts`): karta ma się mieścić na ekranie telefonu (pary idą po dwie, przykład osobno). „Nie tak” to realny błąd polskiego dziecka, a „bo” to powód, nie powtórzenie reguły; skojarzenia muszą działać na słowach z tego samego rozdziału. Pytania kontrolne nie mogą powtarzać zadań tematu (test to sprawdza). Bez wyrażeń regularnych z „lookbehind” — starsze iPady ich nie znają.
- Nowy rozdział podręcznika (np. angielski Unit 1): osobna stała rozdziału w `english5.ts`, tematy z `unit`, id `b-a5-u1-…` i `order` z kolejnej setki (Unit 0: 10–99, Unit 1: 110–199…), żeby rozdziały szły po kolei.
- Ekran zadania na telefonie: całe zadanie ma się mieścić nad stopką bez przewijania na 360×740 (sortowanie: 9 słów i 3 koszyki — pilnuje tego `e2e/types.spec.ts`). Zwarte rozmiary są w zapytaniach `@media (max-width: 640px), (max-height: 560px)` przy danym typie zadania; „Podpowiedź” i „Sprawdź” stoją w jednym rzędzie (`.pr-foot-answer`).
- Nowy motyw: `ThemeId` w `types.ts` → wpis w `THEMES` i `THEME_ORDER` → czcionki w `loadThemeFonts` (paczki `@fontsource`, z `latin-ext`) → blok zmiennych w `styles.css` i sekcja „Motyw: …” na końcu pliku. Reguły miniatur pisz jako `.tp[data-theme='…'] …` (inaczej motyw strony przebija do miniatur innych motywów). Ciemny motyw: jasna zieleń/róż/złoto potrzebują ciemnego tuszu (`--on-bright`, lista selektorów w sekcji Kosmos). Odpowiedzi w zadaniach zostają w szerokim kroju (patrz Wyścigi).
- Bohaterowie: `emoji` jest kluczem (zapisany w `Profile.avatar` i w zakupach `avatar:<emoji>`) — istniejących znaków nie zmieniaj ani nie usuwaj, tylko dopisuj; wybieraj emoji do wersji 11 (stare iPady, Windows 10). Darmowy bohater nie może stać się płatny.
- PIN rodzica ma 6 cyfr (`PIN_LENGTH` w `ParentGate.tsx`); stary krótszy PIN wpuszcza raz i wymusza ustawienie nowego.
- Język obcy: polecenia, wyjaśnienia (`!!`) i podpowiedzi (`??`, zwykle „Po polsku: …”) po polsku; zdania i odpowiedzi w języku obcym; w lukach wszystkie poprawne warianty (`[isn't|is not]`). Podpowiedź i przykłady w `description` nie mogą zdradzać odpowiedzi. Słówka podpowiadamy tylko ze zdania, nigdy z odpowiedzi do wyboru. Test wymaga słówek dla każdego tematu z `ang` i podpowiedzi przy zdaniach.
- Synchronizacja: zmiany w `store.ts` / `merge.ts` sprawdzaj testem `e2e/sync.spec.ts` (dwa urządzenia + atrapa Supabase z REST i WebSocketem) — prawdziwego Supabase w testach nie ma. Osoby, tematy i ustawienia zapisuj zawsze przez `store.put` z aktualnego obiektu ze store (outbox zapamiętuje wersję sprzed zmiany).
- `public/config.js` zawiera prawdziwe konto rodziny (Supabase). Testy przeglądarkowe importują `test` z `e2e/fixtures.ts`, który podmienia konfigurację na lokalną i blokuje zapytania do prawdziwego Supabase — nowe pliki testów też muszą z niego korzystać.
- Przed commitem: `npm test && npm run build`; przy zmianach UI także `CHROME_PATH=... npm run e2e` (testy przeglądarkowe działają na zbudowanym `dist`, więc najpierw `npm run build`).
