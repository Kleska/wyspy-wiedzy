## Zasady merytoryczne

- Przyjęto konwencję podręcznika: 0 należy do liczb naturalnych. Dzielnik musi być niezerowy; 0 ma nieskończenie wiele dodatnich dzielników. Nie dzielimy przez 0.
- 0 i 1 nie są ani pierwsze, ani złożone. 2 jest jedyną parzystą liczbą pierwszą. Nieparzystość nie dowodzi pierwszości.
- NWW dodatnich liczb jest dodatnie. Choć 0 jest wspólną wielokrotnością, nie jest tutaj wynikiem NWW. Nieskończenie wiele różnych wielokrotności mają liczby dodatnie; jedyną wielokrotnością 0 jest 0.
- NWD bierze mniejszą liczbę powtórzeń wspólnych czynników pierwszych, NWW większą liczbę powtórzeń każdego czynnika. Wyjaśnienia rozróżniają liczbę paczek i zawartość paczki, czas oczekiwania i godzinę zdarzenia.
- Rozkłady wymagają zachowania powtarzających się czynników; czynniki w lukach wpisuje się od najmniejszego, zgodnie z poleceniem. Zadanie dopuszczające różne odpowiedzi (np. 53 lub 59) akceptuje wszystkie wskazane poprawne warianty.
- Nie włączono nieudowodnionej hipotezy Goldbacha jako twierdzenia do nauczenia ani zadania zależnego od mapy czy ilustracji, której nie ma na ekranie.
